周期感知 STFT/ACF 评分与 Spilter 尺度裁剪
================================================================================

================================================================================
一、整体流程概览
================================================================================

在 Spilter 架构中，每个客户端只训练一部分 shapelet 尺度（默认 8 选 m）。
为决定哪些尺度最适合某个客户端，需要在联邦训练开始前为每个客户端计算
8 维周期评分向量，衡量该客户端本地数据在 8 个时间尺度上的周期性强度。

对于具有 K 个维度、长度 L 的 MTS 样本 x ∈ R^{K×L}，定义 8 个参考尺度：

  P = {p_1, p_2, ..., p_8} = {0.1L, 0.2L, ..., 0.8L}           (1)

每个参考点 p_r 对应模型中长度为 p_r 的 shapelet 子模块。

周期评分函数 s = period_score(X, α) 的输出为 8 维向量 s ∈ R^8，
其中 s_r 表示尺度 r（参考点 p_r）上的周期强度。计算流程：

  ┌──────────────────────────────────────────────────────────────┐
  │ 对客户端 k 的本地数据 X_k（取前 B 条样本）：                 │
  │                                                              │
  │   s_k = period_score(X_k[0:B], α=β)                          │
  │                                                              │
  │   其中：                                                     │
  │   · s_k[0:4] ← STFT 通道（短周期，p_1 ~ p_4）               │
  │   · s_k[4:8] ← ACF  通道（长周期，p_5 ~ p_8）               │
  │                                                              │
  │   最终：s_k = normalize(s_k) × 10                            │
  └──────────────────────────────────────────────────────────────┘

后续各轮训练直接复用缓存 {s_k}_{k=1}^{K}，不重新计算。

================================================================================
二、period_score 详解：STFT + ACF 双通道周期检测
================================================================================

核心思想：
  · 短周期（高频）模式 → 频域 STFT 更敏感
  · 长周期（低频）模式 → 时域 ACF 更稳定
  · 二者互补，分别覆盖 8 个参考尺度的前后两半

函数签名：
  period_score(x, alpha=0.4)
    输入：x = {x_i}_{i=1}^{N} ∈ R^{N×K×L}
    输出：s ∈ R^8

----------------------------------------------------------------
2.1 STFT 通道：短周期评分（参考点 p_1 ~ p_4）
----------------------------------------------------------------

对每个样本 i ∈ [1, N] 和每个维度 j ∈ [1, min(9, K)]，取信号
x_{i,j}[t], t ∈ [1, L]，进行短时傅里叶变换 (STFT)：

  Z_{i,j}(f, t) = STFT(x_{i,j}[t]; W, H, N_FFT)                   (2)

其中：
  · 窗长 W = max(4, ⌊L/2⌋)
  · 跳步 H = ⌊W/4⌋（75% 重叠）
  · FFT 点数 N_FFT = 8W（8 倍过采样）

功率谱定义为：

  P_{i,j}(f, t) = |Z_{i,j}(f, t)|^2                                (3)

提取高能量区域——取功率谱的前 5% 亮点：

  B_{i,j}(f, t) = 1[P_{i,j}(f, t) ≥ Q_{95}(P_{i,j})]              (4)

其中 Q_{95}(·) 表示 95 分位数阈值。

计算加权中心频率——该维度信号能量最集中的频率位置：

           Σ_f Σ_t  f · P_{i,j}(f,t) · B_{i,j}(f,t)
  f̄_{i,j} = ──────────────────────────────────────────              (5)
            Σ_f Σ_t  P_{i,j}(f,t) · B_{i,j}(f,t)

物理含义：f̄_{i,j} 越大 → 该维度以高频（短周期）振荡为主。

反比映射——中心频率越高，短尺度参考点得分越高：

  d_{i,j} = 1 / f̄_{i,j}   (if f̄_{i,j} > ε, else 0)                (6)

高斯核分配——将反比得分扩散到最近的参考点：

  s_{i,j}^{(STFT)}(r) = exp( -(d_{i,j} - p_r)^2 / (2σ^2) )        (7)

其中 σ = 0.1L 为高斯核带宽。

跨维度聚合——所有维度得分累加：

  s^{(STFT)}(r) = Σ_{i=1}^{N} Σ_{j=1}^{min(9,K)} s_{i,j}^{(STFT)}(r)  (8)

仅保留前 4 个参考点：s^{(STFT)} ∈ R^4。

----------------------------------------------------------------
2.2 ACF 通道：长周期评分（参考点 p_5 ~ p_8）
----------------------------------------------------------------

对每个样本 i 和维度 j，计算自相关函数（使用 FFT 加速）：

  ACF_{i,j}(τ) = E[(x_{i,j}[t] - μ)(x_{i,j}[t+τ] - μ)] / σ²      (9)

其中 μ = E[x_{i,j}[t]]，σ² = Var(x_{i,j}[t])。

在后半滞后区 τ ∈ [L/2, L-1] 进行峰值检测：

  Q_{i,j} = {τ | τ > L/2, ACF_{i,j}(τ) ≥ 0.2,
             ACF_{i,j}(τ) is local maximum}                        (10)

ACF 峰值位置对应信号的主导周期长度。对每个峰值 τ ∈ Q_{i,j}，
计算其与参考点 p_r 的距离倒数得分：

                                          1
  s_{i,j}^{(ACF)}(r) = Σ_{τ∈Q_{i,j}} ──────────────               (11)
                                      |τ - p_r| + ε

其中 ε = 10^{-6} 防止除零。

单个维度归一化后，跨维度聚合：

  s^{(ACF)}(r) = Σ_{i=1}^{N} Σ_{j=1}^{min(9,K)}
                 s_{i,j}^{(ACF)}(r) / Σ_{r'} s_{i,j}^{(ACF)}(r')  (12)

仅保留后 4 个参考点：s^{(ACF)} ∈ R^4。

----------------------------------------------------------------
2.3 融合与输出
----------------------------------------------------------------

加权融合——STFT 覆盖短周期，ACF 覆盖长周期：

  s = [ α · s^{(STFT)}_norm  ‖  (1-α) · s^{(ACF)}_norm ]          (13)

其中 ‖ 表示向量拼接，s^{(·)}_norm 为各自归一化（除以其总和）后的向量。
α ∈ [0, 1] 控制 STFT vs ACF 的权重。

最终归一化并放大：

  s_final = s / (Σ_r s_r + ε) × 10                                 (14)

参数 α（默认 0.4）：
  · α = 1.0 → 纯 STFT
  · α = 0.0 → 纯 ACF
  · α = 0.4 → STFT 占 40%，ACF 占 60%（论文默认值，对应 config 中的 beta）

================================================================================
三、客户端间评分的差异化
================================================================================

由于联邦学习中各客户端的数据是非 IID 的（通过 Dirichlet 分布划分），
不同客户端 k ≠ l 拥有的数据来自不同的类别分布。

设客户端 k 的数据分布为 D_k，则其周期评分向量为：

  s_k = period_score(X_k, α),  X_k ~ D_k                           (15)

因 D_k ≠ D_l，故 s_k ≠ s_l 天然成立。例如：

  · 客户端 A（"步行"为主，高频周期 ≈ 0.2T）→ s_A[0], s_A[1] 高
  · 客户端 B（"静止"为主，无明显周期）→ s_B 各维度均匀且偏低
  · 客户端 C（"跑步"为主，中频周期 ≈ 0.4T-0.6T）→ s_C[3], s_C[4], s_C[5] 高

这种差异化为 Spilter 的尺度裁剪提供了信号处理层面的理论依据——
每个客户端优先选择自身数据周期模式最强的尺度进行本地训练，
从而在有限显存预算下最大化表征学习质量。

================================================================================
四、评分在 Spilter 尺度裁剪中的应用
================================================================================

----------------------------------------------------------------
4.1 预计算与缓存
----------------------------------------------------------------

_precompute_client_scale_scores() 对每个客户端 k 调用一次
_client_scale_scores_batch()，产生评分矩阵：

  S = {s_1, s_2, ..., s_K},  s_k ∈ R^8                             (16)

S 缓存为 cached_client_scale_scores，后续所有轮次复用。
若 period_score 失败（ACF 计算异常），回退为模型特征能量评分：

  s_k^{(energy)}(r) = Σ_{d} ||z_{k, r, d}||²_2                    (17)

其中 z_{k,r,·} 为客户端 k 数据在尺度 r 上的模型前向特征。

----------------------------------------------------------------
4.2 Top-m 分配（local_score_topm）
----------------------------------------------------------------

最简策略——每个客户端独立取周期评分最高的 m 个尺度：

  R_k = {r | rank(s_k[r]) ≤ m}                                     (18)

  优点：本地周期最优，计算零开销
  缺点：无全局覆盖保证。若多数客户端 D_k 相似，某些尺度可能被
        "集体忽视"——即 ∃r: Σ_k 1[r ∈ R_k] ≈ 0

----------------------------------------------------------------
4.3 Knapsack-Lagrangian 分配
----------------------------------------------------------------

在 Top-m 基础上叠加两个物理约束：

  (1) 显存预算约束（OOM 硬约束）：
      g_0 + Σ_{r=1}^{8} g_r · x_{k,r} ≤ B_k    ∀k               (19)

  (2) 全局覆盖约束：
      Σ_{k=1}^{K} x_{k,r} ≥ C_min    ∀r                          (20)

通过 Lagrange 乘子 λ_r ≥ 0 将约束 (20) 松弛到目标函数：

  L(x, λ) = Σ_k Σ_r (s_k[r] + λ_r) · x_{k,r} - Σ_r λ_r · C_min  (21)

分解为 K 个独立 0-1 背包问题——客户端 k 求解：

  max  Σ_r (s_k[r] + λ_r) · x_{k,r}                              (22)
  s.t. g_0 + Σ_r g_r · x_{k,r} ≤ B_k

λ_r 通过次梯度方法更新（衰减步长 η/√(t+1)）：

  λ_r^{(t+1)} ← max(0, λ_r^{(t)} + η/√(t+1) · (C_min - Σ_k x_{k,r}^{(t)}))  (23)

直观解释：
  · λ_r ≈ 0：尺度 r 覆盖充足，无需激励
  · λ_r > 0：尺度 r 覆盖不足，影子价格上涨，吸引客户端将其纳入 R_k

五、关键技术细节
================================================================================

----------------------------------------------------------------
5.1 STFT 参数选择
----------------------------------------------------------------

  W = L/2   — 半序列长度的窗，平衡 Δf 和 Δt
  N_FFT = 8W — 8 倍频域过采样，提高 f̄ 估计精度
  H = W/4    — 75% 时域重叠，确保连续时间片覆盖

参数选择动机：
  · 窗长过大 → 频率分辨率高但时间定位差（长周期信号本身时间定位不重要）
  · 窗长过小 → 时间定位好但频率混叠严重（短周期信号需要频域精度）
  · W = L/2 为经验折中，对 HAR (L=128) 得 W=64

----------------------------------------------------------------
5.2 ACF 峰值检测
----------------------------------------------------------------

  τ ∈ [L/2, L-1] — 仅检测后半滞后区（前半受短期自相关干扰）
  height = 0.2     — 过滤弱自相关噪声
  find_peaks()     — scipy.signal 自动局部极大值检测

ACF 在计算前检查方差：Var(x_{i,j}) < 10^{-12} → 常数序列，跳过。

----------------------------------------------------------------
5.3 跨维度聚合
----------------------------------------------------------------

取前 min(9, K) 个维度参与计算。在高维 MTS（如 DuckDuckGeese 的 1345 维）
中，仅前 9 个维度即可覆盖主要信号成分，避免噪声维度污染评分。

每个维度的评分独立归一化后跨维度累加——等价于对
不同传感器通道的周期信号做"软投票"。

----------------------------------------------------------------
5.4 数值稳定性
----------------------------------------------------------------

全流程多层保护：
  · 分母 < 10^{-12} 时跳过该维度
  · np.nan_to_num(·) 替换所有 NaN/Inf → 0
  · ACF 计算失败 → 回退到模型能量评分 (17)
  · 最终 s_final 保证 Σ_r s_final[r] = 10，除数偏置 ε = 10^{-8}

================================================================================
七、与纯模型能量评分的对比
================================================================================

当 UseACF=False 或 period_score 异常时，回退方案为：

  s_k^{(energy)}(r) = Σ_d ||f_r(x_k)[d]||²_2                     (24)

其中 f_r(·) 为尺度 r 对应的特征切片（dim = 40）。

对比：

  维度        STFT/ACF 评分              模型能量评分
  ───────────────────────────────────────────────────
  计算方式    信号处理（numpy/scipy）     模型前向（PyTorch）
  计算开销    O(NK L log L)              O(NK L) + GPU transfer
  梯度依赖    无                          无（no_grad 模式）
  模型依赖    无                          依赖当前模型参数
  物理含义    周期检测（Hz/lag）          特征活跃度（L2 norm）
  初始化影响  不受影响                    随机初始化导致不稳定
  可解释性    强（"0.2T 处有强周期"）    弱（"尺度 3 特征范数大"）

STFT/ACF 的优势在于：在模型尚未训练的 Round 0，即可为尺度分配
提供有物理意义的周期性先验，避免因随机初始化导致的错误剪枝。

八、与相关工作的关系

· MAST [Liang et al.]：解决的是 ST 编码器训练过程中的激活显存优化
  （checkpointing），与 Spilter 在架构层面做尺度裁剪是正交互补的
  双层优化。
· TS2Vec [Yue et al.]：使用 timestamp-level 和 instance-level
  的层次对比，不做尺度选择。
· ShapeNet [Li et al.]：使用监督学习做 shapelet 选择并依赖标签。
