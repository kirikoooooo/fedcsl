# LSST 下游微调（标签效率）消融结果

## 实验设置

- **数据集**: LSST（天文光变曲线，6 维 × 36 长度，14 类）
  - 训练集 2459 / 测试集 2466（测试集始终完整，不随标注比例裁剪）
- **方法**: Spilter-m2（`configSpilter.yml`，`allocation_mode=local_score_topm`，`--spilter-top-m 2`）
- **联邦设置**: K=50 客户端，Dirichlet α=0.1，**预训练 20 轮**（快速验证运行），numEpoch=1，batch=32，lr=0.01
- **微调协议 A**: 冻结 encoder（`shapelets_blocks` + projection），仅训练单层线性分类头
  - 线性头超参：Adam，lr=1e-3，wd=1e-4，batch≤256，max_epoch=200，ReduceLROnPlateau，seed=42
  - **Checkpoint 口径**：最后一轮（round 20）全局模型
  - **标注子集**：按类别分层采样；每比例 3 个采样种子（0/1/2），报告 mean ± std
  - **验证集规则**：标注子集 ≥ 50 样本时，子集内再按 8:2 分层划验证集用于早停（5%~100% 全部档位均触发）
- **实验日期**: 2026-10-25
- **原始日志**: `result/LSST/2026-10-25-21ft20r_lsst_spilter_m2_l=0.01_lr=0.01_epoch1_alphadir0.1_ft20r_lsst_spilter_m2.txt`

## 结果分析

### 1. 标签效率曲线单调，但低标注区间损失显著

准确率严格单调：5% → 39.4%，10% → 42.4%，20% → 47.5%，50% → 53.1%，100% → 55.9%。

- **5% 仅保留 70.5% 性能**，与 Epilepsy-TSTCC（95.5%）形成鲜明对比；
- 20% → 50% 增益最大（+5.6pp），说明 LSST 需要更多标注样本才能发挥表征能力；
- 50% 时已恢复到 95.1%，100% 仍未达到 SVM 协议水平。

**原因分析（定性）**：
1. **14 类且类别间相似度高**：LR 等线性分类器在低维表征上需要更多样本才能分开 14 个类；
2. **5% 仅约 8.8 样本/类**，分层采样后方差大（±0.024，是 10% 档的 4 倍）；
3. LSST 本身表征质量较弱（SVM 仅 0.587，远低于 Epilepsy 的 0.981），低标注下更容易欠拟合。

### 2. 方差随样本量单调收缩

种子间标准差：5% ±0.0241 → 10% ±0.0059 → 20% ±0.0046 → 50% ±0.0013 → 100% ±0.0020。5% 档的单种子极差达 5.6pp，**该档必须报告多种子**。

### 3. 与 Epilepsy 的对比（同一协议）

| 指标 | Epilepsy-TSTCC | LSST |
|---|---|---|
| 类别数 | 2 | 14 |
| 训练样本 | 7360 | 2459 |
| SVM（最后 10 轮均值） | 0.9810 | 0.5871 |
| 微调 100% | 0.9771 | 0.5587 |
| 微调 5% 保留率 | 95.5% | **70.5%** |
| 每类 5% 样本 | ~184 | ~8.8 |

**结论**：标签效率与"每类可用样本数"强相关。二分类 + 大训练集场景下冻结表征几乎无损；多分类 + 小训练集场景下低标注损失显著，这为论文"标签稀缺"讨论提供了正反两面的证据。

### 4. 与主实验的关系（待补）

主实验 LSST 上 FedU2 全 α 最优（0.6102–0.6201），FedCSL 居中（0.59–0.61），Spilter 未超过 FedU2。本次 20 轮 Spilter-m2 的 SVM 达 0.5871，与主实验 FedCSL 量级一致，说明 20 轮预训练已基本收敛；但**正式结果仍需 200 轮口径复跑**。

## 复现命令

```bash
python -u FedCSL_All.py -dataset LSST \
  --config config/configSpilter.yml --spilter-top-m 2 \
  --num-client 50 --num-rounds 20 --dirichlet-alpha 0.1 \
  --server-gpu 0 --client-workers 1 \
  --ft-ratios 0.05,0.1,0.2,0.5,1.0 --ft-seeds 3 \
  --description "ft20r_lsst_spilter_m2"
```
