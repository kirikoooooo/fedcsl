# Epilepsy-TSTCC 下游微调（标签效率）消融结果

## 实验设置

- **数据集**: Epilepsy-TSTCC（单变量 EEG，T=178，2 类）
  - 训练集 7360 / 验证集 1840 / 测试集 2300（测试集始终完整，不随标注比例裁剪）
- **方法**: Spilter-m2（`configSpilter.yml`，`allocation_mode=local_score_topm`，`--spilter-top-m 2`）
- **联邦设置**: K=50 客户端，Dirichlet α=0.1，200→**本次预训练仅 20 轮**（快速验证运行），numEpoch=1，batch=32，lr=0.01
- **微调协议 A**: 冻结 encoder（`shapelets_blocks` + projection），仅训练单层线性分类头
  - 线性头超参：Adam，lr=1e-3，wd=1e-4，batch≤256，max_epoch=200，ReduceLROnPlateau，seed=42
  - **Checkpoint 口径**：最后一轮（round 20）全局模型
  - **标注子集**：按类别分层采样；每比例 3 个采样种子（0/1/2），报告 mean ± std
  - **验证集规则**：标注子集 ≥ 50 样本时，子集内再按 8:2 分层划验证集用于早停（20%/50%/100% 档）；否则训练集取 best（5%/10% 档）
- **实验日期**: 2026-10-24
- **原始日志**: `result/Epilepsy-TSTCC/2026-10-24-22ft20r_epi_spilter_m2_l=0.01_lr=0.01_epoch1_alphadir0.1_ft20r_epi_spilter_m2.txt`

### SVM 协议对照（同一预训练产物，常规评估协议）

| 口径 | 数值 |
|---|---|
| 最后 10 轮（round 10-19）测试集 SVM 平均准确率 | **0.9810** |
| 单轮最高 testACC | 0.9835（round 7） |
| 与 100% 微调（0.9771）之差 | 0.0039（0.4pp） |

> SVM 协议在训练集全量表征上训练分类器（含 C 网格搜索），微调协议在冻结表征上训线性头；两者口径不同，差值 < 1pp 说明线性头几乎榨干了冻结表征的可分性。

## 结果分析

### 1. 标签效率曲线单调且平滑

准确率随标注比例严格单调上升：5% → 93.3%，10% → 95.3%，20% → 96.6%，50% → 97.2%，100% → 97.7%。

- **5% 即可保留 95.5% 的满标注性能**（仅 ~368 个标注样本），说明 Spilter-m2 学到的 shapelet 表征在小样本下高度可迁移；
- 5% → 10% 是增益最大的一段（+2.0pp），20% 之后边际收益递减（10%→20% +1.3pp，50%→100% 仅 +0.5pp）；
- 结论上可表述为"低标注区间（≤10%）是方法间差异最可能显著的区间"，未来对比实验应重点覆盖 5%/10% 两档。

### 2. 方差随样本量收缩

种子间标准差从 5% 的 ±0.0047 降至 100% 的 ±0.0008。5% 档单种子极差约 1pp，**只用单种子结果不可信**，3 种子是必要下限。

### 3. 与 SVM 协议自洽

100% 微调（0.9771）比最后 10 轮 SVM 均值（0.9810）低 0.4pp。考虑到 SVM 协议用全量训练集且做了 C 网格搜索，而微调配额受 8:2 验证集切分影响（实际只用 80% 标注样本训头），该差距处于合理范围，说明：
- 微调消融实现无系统性 bug；
- 冻结表征的线性可分性主要由编码器决定，分类器形式（SVM vs 线性头）不是瓶颈。

### 4. 与主实验的关系（待补）

主实验 200 轮下 Epilepsy 的模块消融结果为 0.9839（无 Spilter）→ 0.9852（含 Spilter）。本次仅训练 20 轮，SVM 已达 0.9810，**说明 20 轮预训练已能发挥该方法 90%+ 的表征能力**；但为了与论文主表口径一致，**正式结果仍需用 200 轮预训练复跑**。

## 复现命令

```bash
python -u FedCSL_All.py -dataset Epilepsy-TSTCC \
  --config configSpilter.yml --spilter-top-m 2 \
  --num-client 50 --num-rounds 20 --dirichlet-alpha 0.1 \
  --server-gpu 0 --client-workers 1 \
  --ft-ratios 0.05,0.1,0.2,0.5,1.0 --ft-seeds 3 \
  --description "ft20r_epi_spilter_m2"
```

产物：
- 结果日志：`result/Epilepsy-TSTCC/{date}ft20r_epi_spilter_m2_*.txt`（微调块在文件末尾）
- 权重：`checkpoint/Epilepsy-TSTCC/*_model.pt`（best）与 `*_model_final_round.pt`（微调口径）
