## 一键编译

直接执行本目录下的 `build_pdf.sh`：

```bash
bash "论文撰写/build_pdf.sh"                   # 默认编译"论文overleaf[不含omp，含spilter].tex"
bash "论文撰写/build_pdf.sh" 论文overleaf.tex   # 编译另一个 .tex
CLEAN=1 bash "论文撰写/build_pdf.sh"            # 清掉旧中间产物再编（修复引用不刷新）
```

输出：与源 .tex 同名的 PDF（仍带中文与中括号文件名）。

## 编译流程细节

脚本内部做了 3 件关键事：

1. **挂载项目根** —— 把宿主机 `论文/draw/` 整个挂到容器 `/work`，使 .tex 里
   `\includegraphics{../../figs/...}` 能正确解析（仅挂 `论文撰写/` 时
   `../../` 出不出去就找不到图）。
2. **ASCII 临时名规避 bibtex 坑** —— 原文件名
   `论文overleaf[不含omp，含spilter].tex` 含中文 + 中括号 `[ ]`，
   `bibtex` 会报 `Could not open bibtex log file` 拒绝处理。脚本会把它
   `cp` 为 `paper_build.tex` 进行编译，结束后把
   `paper_build.pdf → 论文overleaf[不含omp，含spilter].pdf`。
3. **latexmk -xelatex** —— 自动循环 xelatex → bibtex → xelatex × N，
   直到引用与目录稳定。

容器调用等效命令：

```bash
docker run --rm \
  -v "$ROOT_HOST:/work" -w "/work/fedcsl/论文撰写" \
  --user "$(id -u):$(id -g)" \
  texlive/texlive:latest \
  latexmk -xelatex -shell-escape -interaction=nonstopmode -halt-on-error -f \
  paper_build.tex
```

## 常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| 引用全部 undefined / `\bibliographystyle` 不生效 | 旧 `.bbl` 缓存太老 | `CLEAN=1 bash build_pdf.sh` |
| `! Unable to load picture or PDF file '../../figs/...'` | 挂载根错误 | 使用本脚本（已挂 `论文/draw/`） |
| `bibtex: Could not open bibtex log file` | 文件名含 `[]` | 使用本脚本（已用临时 ASCII 名） |
| `xdvipdfmx:warning: Object @figure.X already defined.` | latexmk 多遍跑导致 PDF 对象重定义 warning | 可忽略，不影响 PDF |
| `pull access denied` | 镜像没拉成功 | `docker pull texlive/texlive:latest` 重试 |

## 镜像信息

| 镜像 | 大小 | 中文 ctex | 用途 |
|------|------|-----------|------|
| `texlive/texlive:latest` | ~5–6 GB | ✅ 自带 fandol/ctex | ⭐ 当前脚本使用 |
| `texlive/texlive:latest-medium` | ~3 GB | ⚠️ 需 `tlmgr install ctex` | 备用 |
| `dxjoke/tectonic-docker` | ~500 MB | ❌ 不支持 ctex | 不可用于本论文 |

首次拉镜像约 5 分钟（4–10 分钟视网速）；之后均为秒级冷启动。
镜像本机已成功拉取并验证。

## Cursor LaTeX-Workshop 集成（可选）

如果想在编辑器里点 build 直接编译，编辑 Cursor 设置：

```json
{
  "latex-workshop.docker.enabled": true,
  "latex-workshop.docker.image.latex": "texlive/texlive:latest"
}
```

或在 shell 启动文件里 export：

```bash
export LATEXWORKSHOP_DOCKER_PATH=docker
export LATEXWORKSHOP_DOCKER_LATEX=texlive/texlive:latest
```

注意：Workshop 内置 `latexmk` wrapper **不会自动绕开文件名中的 `[]`**，
若直接用 Workshop 跑你这个文件，仍会遇到 bibtex 报错。
所以日常更稳的方式是 **terminal 里跑 `build_pdf.sh`**。
