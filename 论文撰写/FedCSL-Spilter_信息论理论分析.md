# FedCSL-Spilter 信息论与互信息视角理论分析

本文尝试从信息论、互信息以及受限资源下的信息选择角度，对 `FedCSL-Spilter` 的设计动机与合理性进行解释。这里的目标并不是给出过强的闭式最优性证明，而是在较温和的假设下，为多尺度 shapelet 学习、周期评分、Spilter 尺度分发以及联邦对齐机制提供统一的理论叙事。

## 1. 多尺度 shapelet 表示的本质：共享语义信息的分解与保留

设原始时间序列记为 `X`，两种随机增强视图记为 `X^{(1)}` 与 `X^{(2)}`。假设它们共享同一潜在语义因子 `C`，例如类别相关模式、局部动态形态、周期结构或跨通道耦合关系，而增强仅引入不改变语义本质的扰动因子 `A`。多尺度 shapelet 编码器输出为

```math
Z=[Z^{(1)},Z^{(2)},\dots,Z^{(R)}],
```

其中 `Z^{(r)}` 表示第 `r` 个尺度上的 shapelet 表征。

从信息论视角看，局部对比学习的核心目的可以表述为最大化两种增强视图表示之间的共享信息，即

```math
\max I\bigl(Z(X^{(1)}); Z(X^{(2)})\bigr).
```

基于 InfoNCE 的对比目标可以看作上述互信息的一个可优化下界，因此 FedCSL 的局部对比学习实际上是在尽量保留增强前后不变的潜在语义因子 `C`。

若进一步按尺度展开，则多尺度目标可以写成

```math
\max \sum_{r=1}^{R}\alpha_r \, I\bigl(Z^{(r)}(X^{(1)}); Z^{(r)}(X^{(2)})\bigr),
```

其中 `\alpha_r` 是第 `r` 个尺度的权重。该式说明，多尺度学习并不是简单地“多加几路特征”，而是在不同时间跨度上分别保持增强不变语义，从而把原始时序中的共享信息分解到多个时间尺度上进行表征。

因此，FedCSL-Spilter 的多尺度 shapelet 结构可以解释为一种**共享语义信息的分层保真机制**：短尺度保留局部瞬时模式，中尺度保留过渡动态，长尺度保留周期与长期依赖。

## 2. 周期评分机制：任务相关信息密度的代理估计

FedCSL-Spilter 使用 STFT 与 ACF 对不同尺度进行周期感知评分，并生成尺度权重 `\pi_{k,r}`。从信息论角度看，这些权重可以解释为客户端 `k` 上“尺度 `r` 与任务相关动态结构之间依赖程度”的代理量。形式上，可将其理解为

```math
\pi_{k,r} \propto I(P_k; Z_k^{(r)}),
```

其中 `P_k` 表示客户端 `k` 的周期/频谱结构因子。

该式的含义是：如果某个尺度上的 shapelet 表征更能刻画当前客户端的主导周期和主频结构，那么该尺度更可能承载与下游判别任务相关的信息，理应获得更高的优化权重。

于是，多尺度损失加权

```math
\sum_{r=1}^{R}\pi_{k,r}\mathcal{L}_{k,r}
```

就可以解释为一种**基于相关信息密度的资源重分配**。它并不追求平均保留所有尺度上的信息，而是优先保留与当前数据统计结构更相关的部分。这与信息瓶颈思想是一致的：在预算固定的情况下，不是保留最大总信息量，而是尽可能保留与任务或共享语义更相关的信息。

## 3. Spilter 尺度分发：受限预算下的信息选择问题

在全尺度训练中，每个客户端都训练全部尺度子模型；而在 Spilter 机制下，客户端 `k` 每轮只训练一个尺度子集 `S_k \subseteq \{1,\dots,R\}`。设尺度 `r` 的系统成本为 `c_r`，可包含通信成本与计算成本；设尺度 `r` 在客户端 `k` 上带来的有效语义收益为 `u_{k,r}`。则 Spilter 的选择过程可以抽象为如下优化问题：

```math
\max_{S_k} \sum_{r\in S_k} u_{k,r}
\quad \text{s.t.}\quad
\sum_{r\in S_k} c_r \le B_k,
```

其中 `B_k` 是客户端 `k` 可承受的本地资源预算。

该式表明，Spilter 本质上不是“少传几个尺度”这么简单，而是在有限资源下，寻找**单位成本带来最大有效信息收益**的尺度组合。进一步地，若令 `u_{k,r}` 由周期评分、尺度响应强度或局部统计稳定性共同近似，则效率感知补发实质上是在估计

```math
\frac{u_{k,r}}{c_r},
```

并优先选择该比值更高的尺度。这使得 Spilter 可被解释为一种**受限通信与计算条件下的信息量最大化策略**。

与随机补发相比，随机选择相当于在上述预算约束问题中忽略了效用函数 `u_{k,r}`；而效率感知 Spilter 则显式利用效用-成本比进行近似最优选择，因此更符合联邦系统中的资源分配目标。

## 4. 从子模优化角度解释 Spilter 贪心选择的合理性

进一步地，可以设尺度集合 `S` 的总体效用函数为

```math
F_k(S)=I(C_k; Z_S),
```

其中 `C_k` 表示客户端 `k` 的共享语义因子，`Z_S` 表示由尺度集合 `S` 共同构成的表示。

如果不同尺度之间存在互补性，但随着已选尺度增加，新增尺度带来的边际收益逐渐减小，那么 `F_k(S)` 可近似视为单调子模函数。也就是说，对于 `A \subseteq B` 和 `r\notin B`，有

```math
F_k(A\cup\{r\})-F_k(A)\ge
F_k(B\cup\{r\})-F_k(B).
```

这表示一个尚未被覆盖的重要尺度，在少量已选尺度时更有价值；当系统已经覆盖了大量相似尺度后，再选该尺度的增益会减弱。该假设与多尺度 shapelet 的实际行为是相容的。

若在预算约束下使用贪心策略按“信息增益/成本比”选尺度，则可借用预算约束子模优化的经典结论：贪心法能够获得一个常数因子的近似最优解。因此，Spilter 的效率感知尺度选择不仅在工程上合理，也可被视作对预算约束信息选择问题的一种近似求解。

## 5. 联邦 non-IID 下的局部-全局对齐：降低表示分布散度

联邦 non-IID 的核心难点在于，各客户端学习到的表示空间可能对应不同的统计分布。设客户端 `k` 的表示分布为 `P_k(Z)`，全局模型对应的表示分布为 `P_g(Z)`。若只进行本地训练，则往往会导致

```math
D\bigl(P_k(Z)\,\|\,P_g(Z)\bigr)
```

不断增大，从而使参数聚合后的全局表示空间失稳。

FedCSL-Spilter 中的 joint CL / KD 与 scale CL / KD 可以理解为约束上述分布散度的机制。设蒸馏或联合对齐项近似最小化

```math
D\bigl(P_k(Z)\,\|\,P_g(Z)\bigr),
```

则在损失函数 `\ell(Z)` 对表示 `Z` 为 `L`-Lipschitz 的条件下，有

```math
\left|
\mathbb{E}_{P_k}\ell(Z)-\mathbb{E}_{P_g}\ell(Z)
\right|
\le
L\cdot \mathrm{TV}\bigl(P_k(Z),P_g(Z)\bigr),
```

其中 `\mathrm{TV}` 为总变差距离。再结合 Pinsker 不等式，

```math
\mathrm{TV}\bigl(P_k(Z),P_g(Z)\bigr)
\le
\sqrt{\frac{1}{2}D_{\mathrm{KL}}\bigl(P_k(Z)\,\|\,P_g(Z)\bigr)}.
```

于是可以得到如下解释：当 joint KD / CL 减小客户端与全局表示分布之间的散度时，客户端损失与全局损失之间的偏差上界也会随之收缩，从而降低 non-IID 条件下的聚合偏移。

这说明 FedCSL-Spilter 中的本地-全局对齐不仅是一个经验技巧，也可解释为**约束表示分布偏移、提升联邦优化稳定性**的机制。

## 6. 多尺度分片通信：信息保持与系统代价之间的折中

在完整模型训练中，所有尺度都被上传与聚合；而在 Spilter 中，仅有被激活的尺度会参与通信。设全尺度通信代价为

```math
\mathcal{C}_{\mathrm{full}}=\sum_{r=1}^{R} c_r,
```

Spilter 的通信代价为

```math
\mathcal{C}_{\mathrm{split}}=\sum_{r\in S_k} c_r.
```

如果未被选中的尺度总体贡献的信息量记为

```math
\Delta I_k = I(C_k; Z_{\{1,\dots,R\}})-I(C_k; Z_{S_k}),
```

则 Spilter 的本质折中可写为：在尽量使 `\Delta I_k` 足够小的前提下，让 `\mathcal{C}_{\mathrm{split}}` 和本地计算复杂度显著下降。

因此，FedCSL-Spilter 可以理解为求解如下风险-资源联合优化问题：

```math
\max_{S_k,\theta}
\Bigl[
I(C_k;Z_{S_k}) - \lambda_c \mathcal{C}_{\mathrm{split}} - \lambda_f \mathcal{F}_{\mathrm{split}}
\Bigr],
```

其中 `\mathcal{F}_{\mathrm{split}}` 表示计算代价，`\lambda_c,\lambda_f` 分别控制通信与计算成本的重要性。

这个形式直接体现了 Spilter 的理论价值：它不是单纯压缩模型，而是在**信息保持**与**系统代价**之间寻找更优平衡。

## 7. FedCSL-Spilter 的统一信息论视角

综合上述分析，FedCSL-Spilter 可以统一表述为：

```math
\max_{S_k,\theta}\;
\sum_{k=1}^{K}
\sum_{r\in S_k}
\pi_{k,r}\,
I\!\left(Z_{k}^{(r,1)}; Z_{k}^{(r,2)}\right)
\;-\;
\lambda D\!\left(P_k(Z)\,\|\,P_g(Z)\right)
```

subject to

```math
\sum_{r\in S_k} c_r \le B_k.
```

其中：

- 第一项表示在多尺度上最大化增强不变语义信息；
- `\pi_{k,r}` 表示周期感知的信息密度加权；
- 第二项表示通过局部-全局对齐抑制表示分布漂移；
- 约束项表示客户端的通信与计算资源限制。

由此，FedCSL-Spilter 可以被理解为一种**联邦预算约束下的多尺度信息保持与选择机制**。其核心思想不是单纯追求更大模型或更少通信，而是在非 IID 联邦环境中，优先保留和传递最有价值、最稳定、且最符合系统预算的那部分多尺度语义信息。

## 8. 可用于论文的凝练表述

可以在论文中采用如下总结性表述：

> 从信息论视角看，FedCSL-Spilter 的目标是在受限通信与计算预算下，最大化多尺度 shapelet 表示对共享语义因子的保留程度。局部对比学习可视为对跨增强互信息下界的优化；周期评分充当尺度相关信息密度的代理，用于提升高价值尺度的优化权重；Spilter 尺度分发进一步把全尺度训练转化为预算约束下的信息选择问题，即优先分发单位成本带来更高信息收益的尺度子模型；局部-全局对齐与知识蒸馏则通过减小客户端与全局表示分布之间的散度，缓解 non-IID 条件下的聚合偏移。因此，FedCSL-Spilter 可以理解为一种联邦预算约束下的多尺度信息保持与选择机制。
