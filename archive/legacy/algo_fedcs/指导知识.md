# 自适应客户端选择方法 (FedCS) 定义

## 1. 方法概述
**目标**：在联邦学习（FL）中，通过优化每轮的客户端采样概率 $q=\{q_1, ..., q_N\}$，最小化达到目标精度所需的**总挂钟时间（Wall-clock Time）**。
**核心创新**：同时考虑**系统异构性**（客户端通信/计算时间 $t_i$）和**统计异构性**（数据分布 $p_i$ 和梯度范数 $G_i$）。
**适用场景**：同步联邦学习（Synchronous FL），部分客户端参与（Partial Participation）。

## 2. 系统模型与变量定义

### 2.1 基本变量
| 符号 | 定义 | 说明 |
| :--- | :--- | :--- |
| $N$ | 客户端总数 | 参与联邦学习的设备数量 |
| $K$ | 每轮采样数 | 每轮随机选择的客户端数量 (通常 $K \ll N$) |
| $i$ | 客户端索引 | $i \in \{1, ..., N\}$ |
| $p_i$ | 数据权重 | $p_i = n_i / n_{tot}$，客户端 $i$ 数据量占总数据量的比例 |
| $t_i$ | 单轮耗时 | 客户端 $i$ 完成一次本地训练 + 通信所需的物理时间 (假设固定) |
| $G_i$ | 梯度范数界 | 客户端 $i$ 的随机梯度期望平方范数的界 ($E\|\nabla F_i\|^2 \leq G_i^2$) |
| $q_i$ | 采样概率 | 客户端 $i$ 在每轮被选中的概率 ($\sum q_i = 1$) |
| $w$ | 模型参数 | 全局模型权重 |
| $E$ | 本地迭代次数 | 每个被选客户端在每轮进行的 SGD 步数 |

### 2.2 未知参数 (需在线估计)
| 符号 | 定义 | 估计方法 |
| :--- | :--- | :--- |
| $\alpha, \beta$ | 收敛 bound 参数 | 通过运行两种基线采样方案（均匀采样、加权采样）估算比率 $\alpha/\beta$ |
| $M$ | 期望单轮时间 | 控制变量 $M = \sum_{i=1}^N q_i t_i$，范围 $[t_{min}, t_{max}]$ |

## 3. 核心算法流程 (Algorithm 2)

该方法分为两个阶段：**参数估计阶段** 和 **优化采样阶段**。

### 3.1 阶段一：参数估计 (Parameter Estimation)
在正式优化采样概率前，需先运行少量轮次以获取 $G_i$ 和 $\alpha/\beta$。

1.  **运行基线方案**：
    *   方案 1 ($q^1$)：均匀采样 ($q_i = 1/N$)。
    *   方案 2 ($q^2$)：加权采样 ($q_i = p_i$)。
    *   分别运行直到达到预设损失值 $F_s$ (无需达到最终精度 $\epsilon$)。
2.  **收集梯度信息**：
    *   被选客户端上传模型更新时，同时上传本地梯度范数 $\|\nabla F_i\|$。
    *   服务器更新 $G_i$ 的估计值（例如使用移动平均或最大值）。
3.  **计算收敛参数比率**：
    *   记录两种方案达到 $F_s$ 所需的轮数 $R_{q1}$ 和 $R_{q2}$。
    *   利用公式估算 $\alpha/\beta$：
        $$ \frac{R_{q1}}{R_{q2}} \approx \frac{\alpha N \sum p_i^2 G_i^2 + \beta}{\alpha \sum p_i G_i^2 + \beta} $$
    *   由此解出比率 $\rho = \alpha / \beta$。

### 3.2 阶段二：优化采样概率 (Optimization)
求解非凸优化问题 P3 的近似解。

1.  **定义优化问题 (P4)**：
    对于固定的期望时间 $M \in [t_1, t_N]$，求解以下凸优化问题得到 $q^*(M)$：
    $$
    \begin{aligned}
    \min_{q} \quad & M \cdot \left( \rho \beta \sum_{i=1}^N \frac{p_i^2 G_i^2}{q_i} + \beta \right) \\
    \text{s.t.} \quad & \sum_{i=1}^N q_i = 1 \\
    & \sum_{i=1}^N q_i t_i = M \\
    & q_i > 0, \forall i
    \end{aligned}
    $$
    *(注：实际代码中可省略常数 $\beta$，目标简化为最小化 $M \cdot (\rho \sum \frac{p_i^2 G_i^2}{q_i} + 1)$)*

2.  **线性搜索 (Linear Search)**：
    *   在区间 $[t_{min}, t_{max}]$ 上以步长 $\epsilon_0$ 遍历 $M$。
    *   对每个 $M$，使用凸优化求解器 (如 CVX, SCS, 或内点法) 求解上述问题得到 $q^*(M)$。
    *   计算对应的目标函数值，选择使总时间最小的 $M^*$ 及其对应的 $q^*$。

3.  **特殊情况闭式解 (Corollary 2)**：
    *   若 $\beta/\alpha \to 0$ (即收敛主要受采样方差影响)，可使用近似闭式解初始化或替代：
        $$ q_i^* = \frac{p_i G_i / \sqrt{t_i}}{\sum_{j=1}^N p_j G_j / \sqrt{t_j}} $$

### 3.3 阶段三：联邦学习训练循环 (Algorithm 1)
使用优化后的 $q^*$ 进行正式训练。

1.  **采样 (Sampling)**：
    *   每轮 $r$，根据概率分布 $q^*$ 有放回地采样 $K$ 个客户端，集合为 $K_r^{(q)}$。
2.  **本地更新 (Computation)**：
    *   被选客户端 $i$ 接收全局模型 $w^r$。
    *   执行 $E$ 步本地 SGD：$w_i^{r+1} = w_i^{r,E}$。
    *   上传 $w_i^{r+1}$ 和梯度范数信息（用于后续更新 $G_i$）。
3.  **自适应聚合 (Aggregation)**：
    *   服务器更新全局模型，**关键步骤**是引入逆概率加权以消除偏差：
        $$ w^{r+1} \leftarrow w^r + \sum_{i \in K_r^{(q)}} \frac{p_i}{K q_i^*} (w_i^{r+1} - w^r) $$
    *   *注意：标准 FedAvg 此处权重通常为 $p_i/|K_r|$，此处必须除以采样概率 $q_i^*$。*

## 4. 代码生成关键逻辑伪代码

```python
class FedCSClientSelection:
    def __init__(self, N, K, t_array, p_array):
        self.N = N
        self.K = K
        self.t = t_array  # [t1, t2, ..., tN] 系统耗时
        self.p = p_array  # [p1, p2, ..., pN] 数据权重
        self.G = np.ones(N) # 初始化梯度界，后续动态更新
        self.q = np.ones(N) / N # 初始化采样概率
        
    def estimate_parameters(self, server, target_loss_fs):
        # 1. 运行 Uniform Sampling
        R_uniform = server.run_fl(sampling='uniform', target_loss=target_loss_fs)
        # 2. 运行 Weighted Sampling (qi = pi)
        self.q = self.p 
        R_weighted = server.run_fl(sampling='weighted', target_loss=target_loss_fs)
        # 3. 收集梯度范数更新 self.G (在 run_fl 过程中完成)
        # 4. 计算 alpha/beta 比率 rho
        # 根据公式 (24) 推导 rho
        sum_p2G2 = np.sum(self.p**2 * self.G**2)
        sum_pG2 = np.sum(self.p * self.G**2)
        # 解方程 (R_uniform / R_weighted) ≈ (alpha*N*sum_p2G2 + beta) / (alpha*sum_pG2 + beta)
        # 得到 rho = alpha / beta
        self.rho = self.solve_rho(R_uniform, R_weighted, sum_p2G2, sum_pG2, self.N)
        
    def optimize_sampling_probabilities(self):
        # 线性搜索 M
        t_min, t_max = np.min(self.t), np.max(self.t)
        best_obj = np.inf
        best_q = self.q
        
        for M in np.linspace(t_min, t_max, num=100):
            # 构建凸优化问题 P4
            # min M * (rho * sum(p_i^2 * G_i^2 / q_i) + 1)
            # s.t. sum(q) = 1, sum(q * t) = M, q > 0
            q_opt = solve_convex_problem(self.p, self.G, self.t, M, self.rho)
            
            obj_val = M * (self.rho * np.sum(self.p**2 * self.G**2 / q_opt) + 1)
            if obj_val < best_obj:
                best_obj = obj_val
                best_q = q_opt
        
        self.q = best_q
        return self.q

    def get_aggregation_weight(self, client_id):
        # 关键：自适应聚合权重
        # weight = p_i / (K * q_i)
        return self.p[client_id] / (self.K * self.q[client_id])
```

## 5. 实现注意事项 (For Code Generation)

1.  **聚合权重修正**：在实现服务器聚合逻辑时，必须使用 $\frac{p_i}{K q_i}$ 而不是标准的 $\frac{p_i}{K}$ 或 $\frac{1}{K}$。这是保证无偏估计的关键。
2.  **凸优化求解**：`solve_convex_problem` 可以使用 `cvxpy` 库。变量为 $q \in \mathbb{R}^N$，目标函数包含 $1/q_i$ 项（这是凸函数）。
3.  **数值稳定性**：$q_i$ 必须大于 0，优化时需设置下界（如 $10^{-5}$）防止除零错误。
4.  **动态更新**：$G_i$ 可以在训练过程中持续更新（如使用指数移动平均），从而定期重新运行 `optimize_sampling_probabilities` 以适应数据分布变化。
5.  **时间参数 $t_i$**：在实际系统中，$t_i$ 可通过历史运行时间的滑动平均值得到，而非固定不变。
6.  **闭式解加速**：如果计算资源受限，可直接使用 Corollary 2 的闭式解 $q_i \propto p_i G_i / \sqrt{t_i}$ 作为近似，虽非全局最优但计算复杂度极低。
