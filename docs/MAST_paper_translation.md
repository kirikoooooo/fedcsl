## 摘要

无监督表示学习在多元时间序列分析中具有巨大潜力，因为它能够在不使用昂贵标签的情况下为许多下游任务学习可泛化的表示。然而，现有的 URL 方法通常采用原本为其他领域（如视觉和语言）设计的模型来编码时间序列数据，并依赖强假设来设计学习目标，这限制了它们的表示能力。为解决这些问题，我们提出了一个新的 MTS 无监督表示学习框架，旨在通过对比学习来学习特定于时间序列的基于 shapelet 的表示。据我们所知，我们是第一个在通用 URL 中探索基于 shapelet 嵌入的工作。为实现这一目标，我们特别设计了一个统一的基于 shapelet 的编码器和一种新颖的多粒度对比与多尺度对齐的学习目标，并开发了一个数据增强库来提高泛化能力。为了进一步在有限的 GPU 显存下实现高效训练，基于广泛使用的激活检查点技术，并考虑到现有通用 AC 规划方法的局限性，我们提出了第一个面向 shapelet 模型的显存感知 AC 规划器。我们在数十个真实世界数据集上进行了广泛实验，并在多种下游任务上评估了我们的方案。结果证明了我们的方法不仅优于 URL 竞争对手，也优于专门为下游任务设计的技术，并展示了我们的 AC 规划器在有限 GPU 显存下提高训练效率的有效性。

**关键词**: 多元时间序列 · 无监督表示学习 · GPU 显存优化  
**代码**: https://github.com/real2fish/CSL

## 1 引言

多元时间序列（MTS）指的是一组随时间演变的相关变量，每个变量通常代表一个实体（如运行中的机器或服务）的某个监控指标（如温度或 CPU 利用率）。MTS 数据的挖掘和分析对于从复杂系统中提取洞察并支持智能决策至关重要，在制造、医药和金融等许多实际场景中发挥着重要作用。

尽管 MTS 越来越多地被各种实际应用收集，但建模它们的一个特殊挑战是缺乏标注或标签。与人类感知自然可理解的图像或文本不同，时间序列数据以高度抽象和不断演变的信号为特征，其隐藏状态即使对于领域专家也可能过于复杂而难以识别。因此，获取标签通常要困难得多。出于这个原因，探索 MTS 的无监督表示学习已成为一个新的趋势。URL 的目标是在不访问标签的情况下训练一个神经网络（称为编码器），将数据映射为特征向量，通过精心设计的学习目标利用原始数据的内在结构来实现。基于 URL，学习到的表示可用于通过使用少量标注数据训练特定任务模型来解决下游分析任务，并且这些特征对不同任务更具通用性。

### 1.1 研究动机

然而，与视觉或语言等领域不同，时间序列背景下的 URL 相对未被充分探索。MTS 通常是具有高噪声、多样时间模式和不同语义含义的连续值数据。由于这些独特的复杂性，上述领域中先进的 URL 方法难以在 MTS 上表现良好。尽管已经有一些尝试通过考虑时间序列的特征来填补这一空白，如时间演变性质和多尺度语义，但现有方法在学习高质量表示方面仍然薄弱。主要原因有两点。

第一，现有的表示编码器设计仍然高度受计算机视觉和自然语言处理经验的启发，这可能不太适合 MTS。具体来说，CNN 和 Transformer 是近期研究中常用的编码器。然而，这些编码器已广泛显示出在应用于 MTS 时由于缺乏处理时间序列特征的能力而面临困难。第二，一些现有方法依赖领域特定假设来设计 URL 目标，如邻域相似性和上下文一致性，这限制了它们对各种场景的泛化。例如，T-Loss 和 TNC 做出直观假设，即时间间隔较大的子序列应该不太相似，但这在周期性序列中容易被违反。

为解决上述问题，我们的核心思想是探索特定于时间序列的表示编码器，且不依赖强假设。特别地，我们考虑基于一种名为 shapelet 的非参数时间序列分析概念的编码器，即显著性子序列，它专门设计为仅从重要时间窗口提取时间序列特征以避免外部噪声。与需要从巨大假设空间中隐式学习时间序列内在结构的通用神经网络不同，基于 shapelet 的特征通过使用原型子序列显式表示时间序列来缩小有效假设空间，这已在分类和聚类等任务中被广泛证明对时间序列更优越。因此，在这样一个有效且缩小的假设空间中进行 URL 可以简化优化过程以提高泛化能力。此外，与通用神经网络提取的特征相比，基于 shapelet 的特征可以更直观地理解时间序列。

### 1.2 挑战与贡献

尽管 shapelet 在上述特定分析任务中取得了进展，它从未在近期兴起的通用表示 URL 课题中被探索。为填补这一空白，我们迈出第一步，提出采用对比学习来学习基于 shapelet 的编码器。

我们强调在学习高质量和通用的基于 shapelet 的表示中存在三个挑战。**第一（C1）**，如何设计一个基于 shapelet 的编码器来捕获各种时间范围的多样时间模式，考虑到它最初设计为仅表示单个形状特征，且需要穷举搜索或先验知识来确定编码尺度。**第二（C2）**，如何使用这个基于 shapelet 的编码器设计一个 URL 目标来学习对下游任务通用信息，这从未被研究。**第三（C3）**，虽然对比学习广泛使用样本及其增强的表示相似性来学习编码器，但如何适当地增强时间序列以确保相似性仍然是一个开放问题。

为应对这些挑战，我们提出了一个名为 Contrastive Shapelet Learning（CSL）的新颖框架。具体来说，为解决 C1，我们设计了一个统一架构，使用多种不同（不）相似度度量和长度的 shapelet 来联合编码 MTS，以捕获从短期到长期的多样化时间模式。由于不同长度的 shapelet 可以分别将一个 MTS 嵌入到不同的表示空间中，且这些空间相互补充，为解决 C2，我们提出了一个多粒度对比目标，同时考虑联合嵌入和每个时间尺度的表示，并平行设计了一个多尺度对齐损失，以鼓励不同尺度的表示达成共识。设计目标是通过利用 shapelet 嵌入的尺度内和尺度间依赖来自动捕获变化的语义。为缓解 C3，我们开发了一个包含多种类型数据增强方法的数据增强库，以进一步提高表示质量。

然而，作为一种特定类型的深度学习模型，CSL 编码器也面临 GPU 显存方面的瓶颈。具体来说，训练期间的 GPU 显存消耗随 MTS 的维度数、长度和批量大小增加而增加，用于存储模型更新所需的中间输出（即激活），但 GPU 中的总显存量通常是有限的，尤其对于许多硬件资源受限的 IoT 应用。

为了在受限的 GPU 显存预算下实现训练，一种有效的解决方案是激活检查点，它只在内存中存储一部分中间输出并在需要时重新计算其余部分。尽管这种方案可以减少 GPU 显存占用，但它由于重算引入的额外开销而减慢了训练速度。因此，为了有效地用计算换取内存，一个关键问题是制定一个检查点计划来决定何时何地丢弃和重算中间结果，以在不耗尽内存的情况下提高训练效率。

不幸的是，现有的通用规划器虽然适用于任意深度模型，但由于其启发式策略或复杂的非线性规划公式难以准确求解，在找到高质量检查点计划方面仍然有限。为了利用 CSL 优越的 URL 性能，为其编码器确定合适的计划以在内存预算内实现高效训练是至关重要但仍然具有挑战性的（**C4**）。

为解决 C4，我们提出了 **MAST**，第一个面向 shapelet 编码器的定制化检查点规划器。与现有的通用规划器决定对所有计算层（如卷积层和 BatchNorm 层）丢弃和重算激活不同（这些层通常具有复杂的数据依赖），MAST 在更精确的空间中确定检查点计划，通过存储或丢弃不同尺度和度量的 shapelet 子模块，因为它们主导了 GPU 显存消耗并且可以独立重算。为搜索在给定显存预算下最大限度地减少训练成本的高质量计划，我们从理论上分析了与检查点计划相关的计算成本和显存消耗。然后，我们将规划问题公式化为一个可以使用标准求解器精确求解的二元线性规划。需要指出的是，MAST 作为一个将 CSL 算法设计与系统效率桥接起来的完整组件，在有限 GPU 显存下实现高效的基于 shapelet 的 URL，这对增强优越的 CSL 方法的实际应用至关重要。

**贡献总结**：
1. 研究如何利用特定于时间序列的 shapelet 表示来提高 URL 性能，这在特定任务中取得了成功但从未被探索用于通用 URL。
2. 提出了一个通过对比学习来学习基于 shapelet 表示的新框架，特别设计了统一的编码器架构和多粒度对比与多尺度对齐的学习目标，并构建了数据增强库。
3. 提出了第一个面向 shapelet 编码器的定制化检查点规划器，决定是否丢弃和重算不同尺度和度量子模块的中间输出，以最小化受限显存预算下的训练计算成本或执行时间。
4. 在来自不同领域的数十个真实数据集上的实验表明：(i) 学习到的表示对分类、聚类和异常检测等许多下游任务是通用的；(ii) 所提方法优于现有 URL 竞争对手，并且可以与分类和聚类的专门技术相媲美甚至更好；(iii) 我们的检查点规划器在相同显存预算下相比当前最先进方法减少 1.43%-7.65% 的训练成本，在相同时间开销下节省 6.4%-21.9% 的 GPU 显存。

## 2 相关工作

### 2.1 无监督 MTS 表示学习

与视觉和自然语言等领域不同，时间序列中 URL 的研究仍处于婴儿期。现有解决方案可分为三类：基于对比学习的方法、基于生成学习的方法和混合方法。

**对比学习**旨在通过鼓励编码器区分相似和不相似的数据样本对来学习有意义的表示。受词表示启发，T-Loss 将最初为自然语言设计的三元组损失适配用于时间序列 URL，通过对比时间步上相邻和远离的子序列。BTSF 使用三元组损失对比不同时间序列样本并结合 MTS 的时域和频域特征。TNC 假设重叠片段之间的语义一致性并对比这些时间邻域和远处片段。TS2Vec 结合时间戳级和上下文序列级对比以实现分层时间序列表示。

**生成学习**通过鼓励表示最大程度地重构或预测时间序列来学习 MTS 的内在结构。自编码是基本且流行的生成方法。近年来，掩码预训练结合 Transformer 已成为潜在的生成范式，基本思想是掩码一部分输入数据并学习可以正确预测掩码部分的表示。

**混合 URL**方案结合了对比和生成技术。TimeDRL 通过同时对比正负样本和重构原始数据来学习 MTS 表示。SimMTM 提出从多个邻居时间序列重构同时对掩码和未掩码输入进行对比。CPC 在潜在表示空间中使用历史数据预测未来并通过最小化对比损失鼓励正确预测。

尽管现有方法在表示质量方面取得了改进，它们仍然存在局限性，如编码器设计缺乏直觉和依赖特定假设。

### 2.2 时间序列 Shapelet

shapelet 的概念最初是为监督时间序列分类任务提出的，它专注于在显著时间范围内提取特征以减少噪声干扰。在早期研究中，shapelet 通过枚举训练时间序列的子序列来选择，存在次优表示和高计算开销的问题。为解决这些问题，shapelet 学习方法首次被提出，直接通过监督目标学习最优 shapelet。除分类外，一些工作将 shapelet 用于时间序列聚类也显示了竞争力。

ShapeNet 是一项与 URL 和 shapelet 都相关的特殊工作，但它仍然专注于从现有候选中选择 shapelet 用于 MTS 分类，并使用 CNN 基础的 URL 方法辅助选择过程，甚至包含使用标签的监督特征选择步骤。相比之下，CSL 和其他 URL 方法针对的是不同的问题——自动"学习"不存在于现有特征集中的新特征，而无需使用标签来处理多个任务。总之，虽然基于 shapelet 的表示已被广泛研究用于分类和聚类任务，它从未像 CSL 这样被探索用于学习通用表示以促进各种任务的无监督学习。

### 2.3 深度模型训练的检查点技术

检查点是减少深度模型训练显存消耗的基本技术，已被 PyTorch 和 TensorFlow 等主流深度学习系统支持。由于检查点通过重算丢弃的中间结果来用训练效率换取内存，一个具有挑战性但至关重要的问题是如何在有限显存预算下制定适当的检查点计划以减少训练开销。

现有规划器主要针对通用模型训练设计。为确保兼容所有可能的层间计算依赖，一些工作设计启发式方法，根据显存使用和重算成本贪心选择层进行检查点。此类方案易于泛化但可能忽略规划任务的全局信息。替代研究以更通用的方式解决问题，将其建模为在显存消耗约束下最小化训练开销的优化问题。然而，公式化的程序包含非线性约束（如多项式或二次型），无法精确求解，限制了解决方案的质量。

为利用所提 CSL 的优越性能并解决现有通用规划器的上述局限性，MAST 是第一个面向 CSL 的 shapelet 模型定制化的检查点规划器，在受限 GPU 显存下提高模型训练效率。

## 3 问题定义

**定义1（多元时间序列）**：MTS 是一组变量，每个变量包含按连续时间排序的观测值。一个具有 $D$ 个变量和 $T$ 个时间戳的 MTS 样本记为 $\mathbf{x} \in \mathbb{R}^{D \times T}$，包含 $N$ 个样本的数据集记为 $\mathbf{X} = \{\mathbf{x}_1, \dots, \mathbf{x}_N\} \in \mathbb{R}^{N \times D \times T}$。

**定义2（MTS 无监督表示学习）**：给定 MTS 数据集 $\mathbf{X}$，URL 的目标是训练一个神经网络编码器 $f: \mathbb{R}^{D \times T} \to \mathbb{R}^{D_{repr}}$，使得表示 $\mathbf{z}_i = f(\mathbf{x}_i)$ 对下游任务（如分类和异常检测）是有信息量的。这里"无监督"意味着下游任务的标签在训练 $f$ 时不可用。

## 4 对比 Shapelet 学习 (CSL)

### 4.1 总体框架

CSL 的通用框架如下：给定输入 $\mathbf{X}$，从库中随机选择两种数据增强方法 $A'$ 和 $A''$ 产生两个相关视图 $\mathbf{X}'$ 和 $\mathbf{X}''$。然后这两个视图被送入称为 Shapelet Transformer (ST) 的特定于时间序列的编码器，将样本嵌入到潜在空间。CSL 探索这个由不同 shapelet 作为基的潜在空间中的表示，不依赖于任务特定假设。

### 4.2 Shapelet Transformer (ST)

ST 编码器的核心是一个统一的架构，使用 $R \times M$ 个 shapelet 子模块 $\{f_{r,m}\}_{r=1,m=1}^{R,M}$，其中 $R$ 为 shapelet 长度尺度的数量，$M$ 为（不）相似度度量的数量。每个子模块 $f_{r,m}$ 使用长度为 $L_r$ 的 shapelet 和度量 $d_m$（Euclidean 距离、Cosine 相似度、Cross-Correlation）将输入 MTS 编码为维度为 $K$ 的表示向量。所有子模块的输出被拼接为最终表示 $\mathbf{z} \in \mathbb{R}^{D_{repr}}$，其中 $D_{repr} = R \times M \times K$。

模型的关键设计包括：
- **多尺度 shapelet**：长度从 $0.1T$ 到 $0.8T$，均匀分布 8 个尺度，捕获从短期到长期的时间模式。
- **多种距离度量**：Euclidean 距离（幅值差异）、Cosine 相似度（形状相似性）、Cross-Correlation（平移不变性）。
- **软正交性正则化**：鼓励同一子模块内的 shapelet 彼此正交，减少冗余。

### 4.3 多粒度对比学习

CSL 的对比目标包含两个粒度级别：

**粗粒度对比（Coarse-grained Contrasting）**：在拼接后的联合表示 $\mathbf{z}'$ 和 $\mathbf{z}''$ 上进行全局对比，使用 InfoNCE 损失：
$$\mathcal{L}_C = -\frac{1}{N}\sum_{i=1}^{N} \log\frac{\exp(\text{sim}(\mathbf{z}'_i, \mathbf{z}''_i)/\tau)}{\sum_{j=1}^{N}\exp(\text{sim}(\mathbf{z}'_i, \mathbf{z}''_j)/\tau)}$$

**细粒度对比（Fine-grained Contrasting）**：在每个尺度 $r$ 上独立进行对比，鼓励编码器在不同时间粒度上学习有区分力的特征：
$$\mathcal{L}_{F,r} = -\frac{1}{N}\sum_{i=1}^{N}\log\frac{\exp(\text{sim}(\mathbf{z}'_{r,i}, \mathbf{z}''_{r,i})/\tau)}{\sum_{j=1}^{N}\exp(\text{sim}(\mathbf{z}'_{r,i}, \mathbf{z}''_{r,j})/\tau)}$$

其中 $\mathbf{z}_{r,i}$ 是样本 $i$ 在尺度 $r$ 上的表示（跨 $M$ 个度量拼接）。

### 4.4 多尺度对齐

为利用不同尺度表示之间的互补性，设计了一个多尺度对齐损失，鼓励相邻尺度的表示达成一致性：
$$\mathcal{L}_A = \sum_{r=1}^{R-1} \|\mathbf{Z}'_r - \mathbf{Z}'_{r+1}\|_F^2 + \|\mathbf{Z}''_r - \mathbf{Z}''_{r+1}\|_F^2$$

### 4.5 数据增强库

构建了包含 5 种时间序列特定增强方法的库：Jittering（添加高斯噪声）、Cropping（随机裁剪）、Time Warping（时间扭曲）、Quantizing（量化）、Pooling（池化）。

### 4.6 总损失

$$\mathcal{L} = \mathcal{L}_C + \lambda_F\sum_{r=1}^{R}\mathcal{L}_{F,r} + \lambda_A\mathcal{L}_A + \lambda_\Omega\mathcal{L}_\Omega$$

其中 $\mathcal{L}_\Omega$ 为软正交性正则化，$\lambda_F$、$\lambda_A$、$\lambda_\Omega$ 为平衡超参数。

## 5 MAST 检查点规划器

### 5.1 检查点预备知识

深度学习模型通常通过迭代更新模型参数来训练。每次迭代有两个阶段：前向传播和反向传播。在前向传播中，mini-batch 的训练样本被送入模型计算分数并推导损失。在反向传播中，损失根据链式法则以与前向传播相反的顺序传播以计算梯度。标准深度学习系统按顺序执行不同层的前向传播并将其输出（激活）存储在显存中以供反向传播复用。在反向传播期间，一旦对应梯度被计算，存储的中间激活即从 GPU 显存中释放。

检查点是一种非常自然且有效的方法来节省 GPU 显存，其做法是在前向传播期间放弃中间结果的存储，并在反向传播需要时重新计算它们。由于不同层的重算成本和显存消耗可能不同，一个关键问题是确定哪些中间激活应存储或重算以在给定显存预算内最大化训练效率——即检查点规划问题。

然而，确定合适的检查点计划可能非常复杂，因为不同层的重算通常具有依赖关系。例如，如果同时丢弃层 $l_2$ 和 $l_3$ 的激活，重算 $l_3$ 的激活必须首先使用前一个存储的层 $l_1$ 重算 $l_2$ 的中间输出，导致递归，引入额外的计算和 GPU 显存消耗。

### 5.2 MAST 设计

针对现有通用检查点规划器的挑战，MAST 是面向 CSL 的 Shapelet Transformer 模型定制化的新规划器。我们的设计基于两个关键观察：

**O1：ST 中的激活存储显存由子模块 $f_{r,m}$ 主导。** 一个子模块 $f_{r,m}$ 中所有 shapelet 的计算由 GPU 使用向量化同时执行，其激活存储约占 $\Theta(BD(T-L_r+1)L_r + BD_{repr}(T-L_r+1))$ 显存。相比下，计算 loss 时的中间输出显存仅约为 $\Theta(BD_{repr})$。因此对于较大的 $B$、$D$ 和 $T$，激活存储显存由子模块主导。

**O2：子模块 $f_{r,m}$ 的重算彼此独立。** 由于不同子模块之间没有数据依赖，任何子模块的激活都可以重算，无论其他子模块的中间结果是否保存。而后续操作（如损失函数）在拼接不同子模块输出的特征上执行，重算它们的中间输出需要重算其依赖但已被丢弃的子模块。

基于以上观察，MAST 的核心思想是通过决定每个主导 GPU 显存且可独立重算的子模块的中间输出在前向传播期间是否丢弃来搜索有效的检查点计划，而推导损失的操作则不使用检查点。这样，我们可以将规划问题建模为二进制线性规划。

**决策变量**：$y_{r,m} \in \{0,1\}$，$y_{r,m}=1$ 表示对 $f_{r,m}$ 使用检查点。

**目标函数**：最小化由检查点引入的额外重算开销：
$$\arg\min_{y} \sum_{r}\sum_{m} y_{r,m} \cdot c_{r,m}$$

其中 $c_{r,m}$ 为 $f_{r,m}$ 的前向计算成本（在运行硬件上 profiling 得到）。

**显存约束**：训练过程中任意时刻的峰值显存不得超过预算 $\mathcal{B}$：
$$p \le \mathcal{B}, \quad \forall p \in \{p_{r,m}, p_L, \tilde{p}_{r,m}, \tilde{p}_L, p^\uparrow_{r,m}\}$$

覆盖五种峰值场景：前向子模块、前向 loss、反向 loss、反向子模块、子模块重算。

**求解**：由于所有符号除 $y$ 外均为常量，该公式为二元线性规划，可使用 Gurobi 等标准求解器精确求解。与硬件无关的常数（$o_{r,m}$、$o_L$、$\varsigma$、$\phi_L$、$\phi_{r,m}$）可从输入数据和参数的尺寸和类型轻松推导，而硬件相关常数（$c_{r,m}$、$w_{r,m}$、$\tilde{w}_{r,m}$、$w_L$、$\tilde{w}_L$）通过在运行硬件上对计算层做 profiling 获取。为在运行时以最小显存消耗获取这些常数，我们在第一个训练 epoch 期间 checkpoint 所有子模块并逐层 profiling。

## 6 实验

### 6.1 实验设置

**数据集**：30 个 UEA 分类数据集 + 4 个异常检测数据集（SMAP, MSL, SMD, ASD）。

**下游任务**：分类（SVM 分类器）、聚类（K-means）、异常检测（Isolation Forest）。

**Baseline**：
- URL 方法：TS2Vec, T-Loss, TNC, TS-TCC, TST
- 分类专用：DTWD, MLSTM-FCNs, TapNet, ShapeNet, OSCNN, DSN
- 聚类专用：MC2PCA, TCK, m-kAVG+ED, m-kDBA, DeTSEC, MUSLA
- 检查点规划器：Mimose, Checkmate, Monet, PyTorch（全模型 checkpoint）

**实现**：PyTorch 1.10.2, Tesla V100 GPU, Scikit-learn 1.1.1, Gurobi 求解器。

### 6.2 主要结果

#### 6.2.1 分类

CSL 在 30 个数据集上的 21 个中取得了 URL 方法中的最佳准确率，在所有方法中也获得了 12 个最佳。平均准确率 0.735（URL 中最高），平均排名 2.08（URL 最佳）。CSL 在统计上显著优于所有 URL 竞争对手（Wilcoxon 检验 p<0.05），并且在 DTWD、MLSTM-FCNs、TapNet 上的表现超越了全监督方法。唯一表现不佳的数据集是 DuckDuckGeese（维度 1345），表明简单地对所有维度的（不）相似度求和可能忽略维度间的复杂相关性，这是 CSL 在高维 MTS 建模上的局限性。

#### 6.2.2 聚类

CSL 优于除 MUSLA 外的所有竞争对手。CSL 和 MUSLA 都基于 shapelet，证明了 shapelet 特征在 MTS 聚类中的优越性。CSL 在平均排名、最佳性能次数和一对一比较胜场数上优于 MUSLA。需强调 MUSLA 是专门的聚类方法，而 CSL 是通用 URL 算法，可用于多种下游任务。

#### 6.2.3 异常检测

CSL 在除 SMD（窗口=100）外的所有设置中均优于 baseline，在 MSL 数据集上超过第二名 TS-TCC 超过 30%。不同数据集上第二名方法各不相同（SMAP 上为 T-Loss，MSL 上为 TS-TCC，SMD 上为 IF-s），说明这些 URL 算法基于领域特定假设难以泛化，而 CSL 展现了更通用的能力。

#### t-SNE 可视化

CSL 学习到的表示形成了更分离的簇，表明更低熵的表示，解释了其在下游任务上的优越性。

### 6.3 消融实验

**(1) 多尺度 Shapelet**：与仅使用短尺度（0.1T-0.4T）或长尺度（0.5T-0.8T）的变体相比，全尺度 CSL 显著更优（p<0.01），证明了使用更广时间范围 shapelet 的必要性。

**(2) 多种距离度量**：三种单一度量变体中 Cross-Correlation 最佳，Euclidean 最差。全度量 CSL 显著优于所有单一度量变体。

**(3) 多粒度对比与多尺度对齐**：分别移除粗粒度对比（$\mathcal{L}_C$）、细粒度对比（$\mathcal{L}_F$）或多尺度对齐（$\mathcal{L}_A$）均导致显著的性能下降。

**(4) 数据增强库**：分别移除 5 种增强方法均导致性能下降，证明了多样数据增强对提升表示质量的重要性。

### 6.4 超参数分析

对尺度数 $R$、每个尺度的 shapelet 数 $K$、表征维度 $D_{repr}$ 进行了敏感性分析。CSL 在较广的参数范围内保持稳定。

### 6.5 部分标注数据

在仅有少量标注数据（1%-10%）的半监督场景中，CSL 显著优于监督方法，证明了其 URL 预训练的有效性。

### 6.6 长序列表示

在 1000-1500 长度的时间序列上，CSL 始终优于 baseline，验证了多尺度 shapelet 在捕获长序列中不同频率模式方面的优势。

### 6.7 可解释性

对学习到的 shapelet 进行可视化，展示了它们对齐到语义上有意义的时间范围，验证了 shapelet 在表示学习中的直观性。

### 6.8 运行时间分析

CSL 的训练时间与 TS2Vec 和 TS-TCC 可比，且在推理阶段由于使用非参数 shapelet 距离计算而更快。

### 6.9 联邦学习评估

在 HAR 数据集上的联邦实验表明 FedCSL 在不同 Dirichlet $\alpha$ 值下始终优于 FedAvg 和 FedProx，展示了 CSL 在隐私保护场景中的潜力。

### 6.10 Scale-CSL 消融

移除 per-scale 的细粒度对比和 KD 损失导致性能显著下降，验证了多尺度对比设计在联邦场景下的必要性。

### 6.11 检查点规划器评估

在 Cricket、DuckDuckGeese、MotorImagery 和 PEMS-SF 四个大数据集上评估。

**(Fig. 14) 归一化训练时间 vs 显存预算**：所有规划器和预算下的归一化时间均小于 1（比 PyTorch 全模型 checkpoint 更快），实际显存消耗一致低于预算（Fig. 15），验证了检查点规划器在受限 GPU 显存下提高训练效率的有效性。MAST 始终优于 baseline，相比 PyTorch 实现 1.21×-2.72× 加速。与 Mimose、Checkmate、Monet 相比，MAST 在相同预算下减少 1.43%-7.65% 时间开销，在相同计算开销下节省 6.4%-21.9% 显存。

**(Fig. 15) 实际显存消耗 vs 预算**：MAST 在某些情况下使用更多显存（但始终在预算内），这反而带来更高效率——用显存换取训练时间。在其他情况下，MAST 可用更少的显存达到更快的速度，表明其计划能更好地利用有限显存减少高成本层的重算。

**(Fig. 16) 显存时间曲线**：在 MI 数据集 16 GB 预算下，MAST 相比 Checkmate 的全局峰值显存低 4.7%，反向传播耗时更短（更少重算开销）。

**(Fig. 17) 扩展性分析**：随 batch size（$B$）、维度数（$D$）和序列长度（$T$）增加，MAST 始终保持最高训练效率。当数据规模增大时，MAST 与其他规划器的差距进一步扩大。

## 7 结论

本文提出 CSL，首个基于 shapelet 的通用 URL 框架，设计了统一的多尺度 shapelet 编码器、多粒度对比与多尺度对齐学习目标，以及数据增强库。进一步提出 MAST，首个面向 shapelet 模型的定制化检查点规划器，利用子模块独立性和显存主导特性将规划问题建模为可精确求解的二元线性规划。大量实验证明了 CSL 在分类、聚类和异常检测等任务上的优越性，以及 MAST 在有限 GPU 显存下提升训练效率的有效性。
